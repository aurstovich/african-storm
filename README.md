# Африканский шторм (African Storm)

Городская стратегия в реальном времени (RTS) на JavaScript и HTML5 Canvas. 
Действие происходит в вымышленном городе Гурун, где две стороны — Гурундия и Бурундия — сражаются за контроль над кварталами, используя советскую военную технику и вооружение.

## 🎮 Геймплей

*   **Управление отрядами:** Выделяйте группы мышью или пальцем (на мобильных). Отдавайте приказы на движение, атаку или занятие зданий.
*   **Гарнизоны:** Прячьте отряды в зданиях. На крышах появляются точки-солдаты, которые получают бонус к защите и дальности стрельбы. Выходить из здания можно в любую сторону, указав курсором.
*   **Экономика:** Захватывайте здания, чтобы получать очки. Тратьте их на подкрепления (пехота — 12 сек, снайперы — 16 сек).
*   **Туман войны:** Вы видите только то, что находится в радиусе обзора ваших юнитов. Юниты и ИИ не могут стрелять сквозь стены.
*   **Умный ИИ:** Противник (Бурундия) не просто бежит в атаку. Он распределяет роли (захват, оборона, ударная группа), отступает при потере половины бойцов, запоминает ваши позиции и обходит препятствия.

## 🛠 Технические особенности

*   **Модульная архитектура:** Код разбит на 15 логических файлов (модули JS) для удобства поддержки.
*   **Сохранения:** Прогресс сохраняется в `localStorage` (вручную или автосохранением каждые 30 секунд).
*   **Мобильная адаптация:** Поддержка тач-управления (выделение пальцем, пинч-зум, долгое нажатие для приказа). Интерфейс подстраивается под экраны телефонов.
*   **Синтезированный звук:** Выстрелы и взрывы генерируются через Web Audio API (без внешних файлов).
*   **Визуальный стиль:** Вид сверху (top-down), мрачная атмосфера разрушенного города, следы боёв (воронки, трупы, обломки).

## 🚀 Как запустить локально

Для запуска игры на компьютере вам понадобится локальный сервер (из-за использования ES-модулей).

1. Скачайте репозиторий или клонируйте его:
   ```bash
   git clone https://github.com/aurstovich/african-storm.git

  2. Откройте терминал в папке с игрой.

3. Запустите локальный сервер (например, через Python):
python -m http.server 8000
4. Откройте в браузере: http://localhost:8000

 Как играть (ПК)
 
ЛКМ — выделить отряд или рамкой.

ПКМ — приказ идти, атаковать или зайти в здание.

1 / 2 — купить пехоту / снайперов (появляются в точке курсора).

A — атаковать ближайшего врага или идти к курсору.

E — остановить отряд (сброс приказов).

Q — снять выделение.

F1–F5 — группы отрядов (Ctrl+F1 — назначить).

Пробел — центрировать камеру на выделенных.

H — центрировать камеру на базе.

WASD — движение камеры.

Колесо — зум.

Esc — пауза.

F5 — быстрое сохранение.
