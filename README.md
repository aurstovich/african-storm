# Африканский шторм

Браузерная городская RTS: Гурундия против Бурундии в вымышленном городе Гурун.

**▶ Играть: [aurstovich.github.io/african-storm](https://aurstovich.github.io/african-storm/)**

![Город, подкрепления и гарнизон](docs/screens/spawn.png)

## Об игре

Вы командуете отрядами Гурундии на процедурно собранной карте города 2000×2000. База — у левого края, база противника — у правого, между ними кварталы: дома, заводы и штаб, за которые идёт борьба.

Победа не выдаётся за уничтожение чего-то одного: сторона считается разбитой, когда у неё не осталось ни живых отрядов, ни захваченных зданий. То же правило действует и против вас.

## Возможности

**Отряды и бой**

- Четыре типа подразделений: пехота (7 бойцов, гранаты), снайперы (4), РПГ-расчёт (2, против танков) и Т-62.
- У танка отдельная модель прочности: стрелковое оружие его не берёт, РПГ и танковый снаряд снимают половину за попадание, граната — всего 5%.
- У пехоты гранаты с радиусом броска и разбросом: часть бойцов гибнет сразу, часть получает ранение.
- Отряд редеет постепенно: пока живы здоровые бойцы, урон уходит в раненых, и только когда раненых становится не меньше, чем здоровых, начинаются потери.
- Линия огня честная: здание между стрелком и целью блокирует выстрел.

**Гарнизоны**

- В дом входит до двух отрядов. Внутри — бонус к защите и к дальности стрельбы.
- На крыше видно самих бойцов: они занимают позиции по периметру и внутри крыши, разворачиваются наружу, а раненые лежат.
- Выходить можно в любую сторону — отряд пойдёт туда, куда указан курсор.
- Захват здания — это присутствие гарнизона: ушли бойцы, дом снова нейтрален.

**Экономика и мораль**

- Доход начисляется за каждое удерживаемое здание каждые 3 секунды.
- Потери бьют по морали: подкрепления дорожают и производятся дольше, а урон падает. Мораль видна в HUD обеих сторон.
- Подкрепления выходят с внешней стороны базы: у игрока — слева, у ИИ — справа. Вокруг баз застройка не появляется, чтобы плац всегда был свободен.

**Туман войны и ИИ**

- Видно только то, что в радиусе обзора своих отрядов; разведанная, но не наблюдаемая местность затемнена, а не скрыта полностью.
- ИИ Бурундии распределяет роли (захват, оборона, ударная группа), копит силы перед наступлением, отступает при потере около 40% армии и запоминает позиции ваших отрядов.
- Три уровня сложности меняют скорость производства у сторон, агрессивность ИИ и его доход.
- Песочница: неограниченные очки и мгновенный спавн для экспериментов.

## Управление

| Действие | Клавиши |
|---|---|
| Выделить отряд или рамкой | ЛКМ |
| Приказ: идти / атаковать / войти в здание | ПКМ |
| Купить пехоту / снайперов / РПГ / танк | `1` / `2` / `3` / `4` |
| Атаковать ближайшего или идти к курсору | `A` |
| Остановить отряд | `E` |
| Снять выделение | `Q` |
| Группы отрядов | `F1`–`F4`, назначить — `Ctrl+F1`–`F5` |
| Центрировать камеру на выделенных / на базе | `Пробел` / `H` |
| Движение камеры | `WASD` или зажатая средняя кнопка мыши |
| Зум | колесо мыши |
| Пауза и меню | `Esc` |
| Свернуть или развернуть правую панель | `Tab` |
| Быстрое сохранение | `F5` |

Сенсорное управление пока не сделано: интерфейс подстраивается под узкие экраны, но играть нужно мышью и клавиатурой.

| Юнит | Цена | Особенность |

| 🪖 Пехота (7 бойцов) | 2 ⭐ | Гранаты, 14 штук на отряд |

| 💥 РПГ-расчёт (2 бойца) | 4 ⭐ | Против танков |
| 🚀 Танк Т-62 | 6 ⭐ | Неуязвим для стрелкового оружия |

Танк уничтожают два попадания РПГ или танкового снаряда. Гранаты снимают по 5% прочности, поэтому пехоте нужно двадцать попаданий.

## Технические детали

- **PixiJS 8** (WebGL/WebGPU) и **Vite 5**, чистые ES-модули без фреймворков.
- **Статический мир запекается в текстуру 2000×2000**: земля, дороги, декор и крыши зданий рисуются один раз, в кадре остаётся один спрайт.
- **Туман войны — текстура 80×80**, где клетка сетки равна пикселю; растягивается на мир с линейной фильтрацией, поэтому границы мягкие.
- **A\* по сетке 25 px** с расширением зданий на радиус отряда: танк и пехота обходят препятствия по-разному.
- **Пулы объектов** для эффектов и всплывающего текста, сохранения в `localStorage`, звук через Web Audio.

## Лор

Город Гурун — последний оплот цивилизации. После распада власти регион разделился на Гурундию и Бурундию: запад держит Гурундия, восток — Бурундия.

Это не война за идею. Это война за выживание — за кварталы, воду и крышу над головой.

## Сборка

В репозитории лежит готовая сборка: `index.html`, `assets/` и `sounds/`. GitHub Pages отдаёт её прямо из корня ветки `main`, поэтому обновление игры — это пересборка и замена файлов:

```bash
npm install
npm run build
# затем содержимое dist/ копируется в корень репозитория:
# index.html, assets/, sounds/
```

Исходники (`src/`, `css/`, `package.json`) в репозиторий не входят — он служит витриной и хостингом демо.
