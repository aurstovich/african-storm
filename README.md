# 🎮 Африканский шторм

Браузерная RTS про войну в вымышленном городе Гурун. Гурундия (синие) против Бурундии (красные). Выживет только один.

**Играть:** [aurstovich.github.io/african-storm](https://aurstovich.github.io/african-storm/)

---

## 🕹 Управление

- **ЛКМ** — выделить
- **ПКМ** — идти / атаковать / войти в здание
- **1 / 2 / 3 / 4** — купить пехоту / снайперов / танк / РПГ
- **A** — атаковать, **E** — стоп, **Q** — снять выделение
- **WASD** — камера, **колесо** — зум
- **Esc** — пауза, **F5** — сохранить

---

## ⚔️ Юниты

| Юнит | Цена | Особенность |
|---|---|---|
| 🪖 Пехота (7) | 2 ⭐ | Гранаты |
| 🎯 Снайперы (4) | 3 ⭐ | Мгновенная смерть |
| 💥 РПГ (2) | 4 ⭐ | Убивает танки |
| 🚀 Танк Т-62 | 6 ⭐ | Неуязвим для пуль |

**Танк** можно убить только РПГ, другим танком или гранатой.
